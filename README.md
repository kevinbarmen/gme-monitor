# GME-монитор

Информационный монитор по акции GameStop (GME): собирает Reddit, новости и филинги SEC,
отсеивает шум и раз в день присылает в Telegram дайджест. Срочные алерты приходят только
по трём фактическим поводам. **Это не торговый бот и не источник рекомендаций.**

```
Reddit ─┐                      слой 1: эвристики          слой 2: Claude (1 батч в день)
Новости ├─> SQLite ──> (апвоты, флеары, стоп-слова, ──> (оценка 1-10, категория, ──> TG-дайджест
SEC ────┘                дедупликация)                   саммари на русском)
   │
   └──> алерты при каждом сборе: SEC 8-K/13D/G · цена ±15% · аномальный апвот-темп ──> TG
```

## Установка

```bash
cd ~/gme-monitor            # на Windows: C:\Users\<user>\gme-monitor
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt      # Windows: .venv\Scripts\pip ...
cp .env.example .env                             # и заполнить
```

Что положить в `.env`:

| ключ | откуда |
|---|---|
| `GME_TG_BOT_TOKEN` | **новый** бот через @BotFather (не бот CS2-модели) |
| `GME_TG_CHAT_ID` | ваш chat id: написать боту, затем открыть `https://api.telegram.org/bot<TOKEN>/getUpdates` |
| `ANTHROPIC_API_KEY` | console.anthropic.com |
| `SEC_USER_AGENT` | `"gme-monitor Имя email"` — SEC требует контакт, иначе блокирует |
| `REDDIT_CLIENT_ID` / `REDDIT_CLIENT_SECRET` | опционально, см. «Reddit» ниже |
| `HEARTBEAT_TG_BOT_TOKEN` / `HEARTBEAT_TG_CHAT_ID` | для heartbeat.py (можно тот же GME-бот) |

Без TG-токена всё работает в режиме dry-run: сообщения печатаются в консоль.

## Запуск

```bash
.venv/bin/python run.py collect          # сбор + фильтр + алерты
.venv/bin/python run.py digest           # скоринг Claude + дайджест (раз в сутки; --force — повторно)
.venv/bin/python run.py status           # здоровье источников, сколько чего собрано/отсеяно
.venv/bin/python heartbeat.py --dry-run  # строка статуса всех систем
```

## Расписание

Команда `run.py print-cron` печатает строки crontab из `config.yaml` (секция `schedule`,
время дайджеста — `digest.time`):

```bash
.venv/bin/python run.py print-cron            # Linux → вставить в crontab -e
.venv/bin/python run.py print-cron --windows  # Windows → команды schtasks
```

По умолчанию: сбор в нечётные часы в `HH:23`, дайджест в 09:50, heartbeat в 10:07.

На Windows уже установлено (Планировщик заданий, запуск через `pythonw.exe` без окна):
`GME Collect`, `GME Digest`, `Systems Heartbeat`. Время подобрано мимо задач CS2
(:00 по чётным часам, :32, :11/:41, каждые 5 мин, CS2 Heartbeat в 09:30).
**Перед установкой сверьте минуты с задачами CS2-модели** (`crontab -l`) — тяжёлые джобы
не должны стартовать в одну минуту. Процесс короткий: сетевые запросы и выход, демонов нет.

## Источники

Все источники — списки в `config.yaml`. Новый сабреддит или RSS-фид = одна запись в конфиге.

- **Reddit**: Superstonk, GME, DeepFuckingValue (бычьи) + stocks (нейтральный, обязателен,
  только посты по запросу `GME OR GameStop`). Режим выбирается сам:
  1. **OAuth** — если в `.env` есть `REDDIT_CLIENT_ID`/`SECRET` (приложение типа *script* на
     reddit.com/prefs/apps). Полные данные: апвоты, флеары, апвот-темп.
  2. **Публичный JSON** — `top.json`/`hot.json`. С многих IP Reddit сейчас отвечает 403.
  3. **RSS** — работает без ключей, но без апвотов и флеаров: вместо порога апвотов берутся
     первые `rss_top_n` постов топа/горячего, **алерт по апвот-темпу в этом режиме не работает**.
- **Новости**: Google News RSS (`GameStop OR GME`), Yahoo Finance RSS. Дедупликация по URL и по
  схожести заголовков, стоп-слова для кликбейта.
- **SEC EDGAR**: `data.sec.gov/submissions` по CIK GameStop. Любой новый филинг из списка форм
  попадает в дайджест без фильтрации; 8-K расшифровывается по items. При первом запуске история
  записывается как база, алертов по ней нет.
- **Цена**: chart-эндпоинт Yahoo Finance (тот же, что использует yfinance), без pandas.

## Фильтрация

1. **Эвристики** (без API): мин. апвоты по сабреддиту, флеары мемов, посты без текста и без
   ссылок (картинки i.redd.it и т.п. считаются «без ссылки»), стоп-слова, дубли новостей.
2. **Claude** (раз в день, один запрос на всё): оценка 1-10, категория, саммари 2-3 предложения
   на русском. Хайп/сентимент получает ≤3 и в дайджест не попадает (`scoring.min_score`).
   Модель, effort и промпт — в `config.yaml → scoring`. Если Claude недоступен, дайджест всё
   равно уходит: с пометкой об ошибке и топом по эвристикам без саммари.

## Алерты (только три)

1. Новый SEC-филинг из `sec.alert_forms` (8-K, 13D, первичный 13G).
2. Движение цены за день больше `price.alert_move_pct` (±15%) — не чаще раза в день на направление.
3. Апвот-темп поста выше `velocity_ups_per_hour` сабреддита (нужен OAuth/JSON-режим).
   Пороги стартовые, подстройте по первым неделям.

Каждый алерт отправляется один раз (таблица `alerts` в SQLite).

## Здоровье и логи

- `data/logs/monitor.log` — общий лог; `data/logs/source_errors.log` — только ошибки источников,
  чтобы отличать «тишину в данных» от «сломался парсер».
- Источник лежит дольше `health.source_down_alert_hours` (24 ч) → сообщение в TG.
- `run.py status` — сводка по источникам и причинам отсева.

## Heartbeat

`heartbeat.py` + `heartbeat.yaml` архитектурно независимы (ничего не импортируют из монитора).
Раз в сутки шлёт одну строку: `CS2: жива, последний цикл … / GME: жив, последний сбор …`,
а если маячок старше порога — `⚠ молчит с …`. Новая система = новый маячок + запись в yaml.

GME-монитор пишет маячок `~/status/gme.ts` после каждого сбора. **В CS2-модель** добавьте
после успешного цикла (это единственное изменение в её коде):

```python
(__import__("pathlib").Path.home() / "status").mkdir(exist_ok=True); (__import__("pathlib").Path.home() / "status" / "cs2.ts").write_text(str(__import__("time").time()))
```

## Изоляция от CS2-модели

Отдельная папка/репозиторий, свой `.venv`, своя база `data/gme.db`, свой `.env`, отдельный
TG-бот. Общих файлов и импортов нет; единственная точка соприкосновения — папка маячков `~/status/`.

## Структура

```
run.py          CLI: collect / digest / status / print-cron
core.py         конфиг, SQLite, HTTP (rate limit, ETag-кэш, 429-повтор), Telegram, маячок, лок
sources/        reddit.py, news.py, sec.py, price.py — по модулю на тип источника
filter.py       слой 1 — эвристики
scorer.py       слой 2 — Claude, один батч
digest.py       ежедневный дайджест
alerts.py       три триггера + сообщение о падении источника
heartbeat.py    статус всех систем (независимый)
config.yaml     все настройки;  .env — ключи
```
